# نسخه وب مدیریتی (Interactive Report)

فایل اصلی گزارش بصری تعاملی در ریشه پروژه یا به‌صورت `tv360_strategy_web.html` در اختیار تیم قرار دارد.

این نسخه وب شامل:
- داشبورد KPIهای کلیدی
- نمودار ترکیب هدف و تقاضا بر اساس سایز
- جداول سبد محصول اسنوا و دوو
- معماری برند
- ماتریس تاب‌آوری اینترنت
- بنچمارک جهانی
- نقشه راه ۴ مرحله‌ای
- تصمیمات هیئت‌مدیره

برای مشاهده کامل، فایل HTML را در مرورگر باز کنید (حالت ارائه و چاپ پشتیبانی می‌شود).

**نکته:** نسخه وب بر اساس داده‌های اولیه فایل پلن ساخته شده و اختلافات حجمی را به‌صورت بصری برجسته می‌کند. نسخه متنی استراتژی (`docs/strategy.md`) بازنگری‌شده‌تر و سخت‌گیرانه‌تر است.
