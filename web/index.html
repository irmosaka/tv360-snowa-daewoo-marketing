نسخه تعاملی کامل

نسخه کاملاً تعاملی و اصلی که اول فرستادی (با تب‌ها، نمودارها، حالت ارائه، progress bar و همه قابلیت‌ها) به دلیل حجم بالا و محدودیت ابزار آپلود مستقیم، هنوز به‌صورت کامل روی Pages قرار نگرفته.

راه حل سریع:

  1. فایل اصلی tv360_strategy_web.html رو از سیستم خودت بردار
  2. در مخزن گیت‌هاب → Add file → Upload files
  3. فایل رو به نام index.html در ریشه یا داخل پوشه docs آپلود کن
  4. بعد از عمومی کردن مخزن و فعال کردن Pages، صفحه تعاملی کامل در دسترس خواهد بود
