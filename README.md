## فعال‌سازی صفحه عمومی (GitHub Pages)

1. مخزن را **Public** کنید:
   - Settings → Danger Zone → Change visibility → Make public

2. فایل اصلی تعاملی را آپلود کنید:
   - Add file → Upload files
   - فایل `tv360_strategy_web.html` را انتخاب کنید
   - نام آن را به `index.html` تغییر دهید و در ریشه بگذارید

3. GitHub Pages را روشن کنید:
   - Settings → Pages
   - Source: Deploy from a branch
   - Branch: `main` / folder: `/ (root)`
   - Save

بعد از ۱–۲ دقیقه صفحه کامل تعاملی در این آدرس در دسترس خواهد بود:
